# Reference

The reference section points at the stable seams between the documentation,
runtime, and source corpus.

- [Service map](/reference/service-map) lists current repository boundaries.
- [Vault API](/reference/vault-api) documents the Purin Vault public surface,
  the external import boundary, and the credential migration procedure.
- [Contracts and bindings](/reference/contracts) explains where domain types
  live and how generated bindings move.
- [Plans and decisions](/reference/plans) describes which source documents own
  product direction, architecture, operations, and evidence.

The top-level `docs/` directory remains authoritative for detailed plans,
evidence, specifications, and runbooks. These pages provide the navigable
orientation layer.
