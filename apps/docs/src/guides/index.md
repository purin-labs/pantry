# Guides

Use the guides after reading the architecture concepts. They describe the
operating paths that Pantry supports today and the boundaries that future work must
preserve.

## Product paths

- [Merchant onboarding](/guides/merchant-onboarding): connect an organisation,
  select authority, pass readiness, and activate operations.
- [Commerce operations](/guides/commerce-operations): operate café, patisserie,
  packaged-goods, and flavored export paths.
- [First operating path](/guides/first-operating-path): trace an accepted
  order through production and dispatch.

## Platform paths

- [Integrations](/guides/integrations): understand Slack, commerce, payment,
  provider, and model connections.
- [WhatsApp customer support](/guides/whatsapp-customer-support): receive a
  customer text as a Case, approve a response, summarize active work in Slack,
  and verify cleanup.
- [Bakery automation](/guides/bakery-automation): follow the measured robot
  adapter direction and its safety boundary.

## Status language

The docs distinguish three states:

- **Current** means the repository and runtime support the path.
- **Measured path** means the path is the next acceptance slice and has an
  explicit evidence gate.
- **Deferred** means the design is recorded while implementation remains out
  of the active runtime.
